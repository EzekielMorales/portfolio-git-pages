### ✨ Key Highlights & Features

Built to be fast, responsive, and engaging with a developer-first aesthetic:

* 🧪 **Playwright QA Test Simulator:** Interactive in-browser runner that simulates running automated E2E test suites with real-time progress and synthesized audio feedback.
* 💻 **Interactive CLI Terminal:** A functional command-line widget where visitors can type commands (`help`, `test`, `skills`, `projects`, `contact`, `cv`) or tap quick-action chips.
* 🎴 **3D Perspective & Spotlight:** Custom physics-based 3D card tilt and mouse-tracking radial spotlight effect.
* 🌌 **Particle Constellation Canvas:** Lightweight HTML5 Canvas network reacting smoothly to cursor movement.
* 🔤 **Developer Typography:** Clean, readable typography powered by **JetBrains Mono**.
* 📄 **Direct Resume Access:** Integrated view and download for `Supasit_CV.pdf`.
